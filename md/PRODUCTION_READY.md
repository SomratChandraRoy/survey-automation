## 🚀 Deployment Instructions

### Prerequisites (5 minutes)
1. Ubuntu 20.04+ server
2. Opinion Edge account
3. 2Captcha account ($5-10 credit)
4. Server access (SSH)

### Deployment (15 minutes)

**Step 1: Clone and Configure**
```bash
git clone https://github.com/yourusername/opinion-edge-automation.git
cd opinion-edge-automation
cp .env.example .env
nano .env  # Add credentials
```

**Step 2: Deploy**
```bash
chmod +x deploy.sh
./deploy.sh
```

**Step 3: Verify**
```bash
sudo systemctl status survey-automation
tail -f logs/automation.log
# Open: http://your-server-ip:5000
```
